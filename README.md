Mini‑Dashboard zur Verwaltung und Anzeige von Produktdaten (WPF, C#, SQLite) | 'MiniProductManager' 
Eigenständiges Projekt zur Vorbereitung auf praktische Aufgaben im Bereich C#/WPF/SQL.

In diesem Projekt entwickle ich eine kleine Desktop‑Anwendung mit WPF und C#, die das Anlegen, Anzeigen, Bearbeiten und Löschen von Produktdaten ermöglicht. 
Die Benutzeroberfläche wird in XAML erstellt und umfasst Eingabefelder für Produktname und Preis, eine Liste zur Darstellung aller gespeicherten Produkte sowie 
Schaltflächen für CRUD‑Operationen. 

Die Daten werden in einer lokalen SQLite‑Datenbank gespeichert und über SQL‑Abfragen (SELECT, INSERT, UPDATE, DELETE) verarbeitet. 
Die Anwendung verbindet die grafische Oberfläche mit der Datenbanklogik und bildet damit einen vollständigen, praxisnahen Workflow ab, wie er in typischen internen
Tools in Unternehmen vorkommt.
